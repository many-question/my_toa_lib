# V1_decap

Schematic of the Virtuoso cell `decap/V1_decap` (view schematic), exported with rnl-virtuoso and turned into a TOA circuit with toa-virtuoso.

- `V1_decap.scs`: the Spectre netlist, with its drawing in RNL 0.4 records.
- `eda-symbol.rnl`, `eda-style.rnl`: the symbol and style packages the drawing uses (CC0-1.0).
- Subcircuits: none.
- The models of the devices of the process `tsmc28` are not included.
