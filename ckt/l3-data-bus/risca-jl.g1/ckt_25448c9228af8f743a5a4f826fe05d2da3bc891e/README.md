# L3_data_bus

Schematic of the Virtuoso cell `RISCA_JL/L3_data_bus` (view schematic), exported with rnl-virtuoso and turned into a TOA circuit with toa-virtuoso.

- `L3_data_bus.scs`: the Spectre netlist, with its drawing in RNL 0.4 records.
- `eda-symbol.rnl`, `eda-style.rnl`: the symbol and style packages the drawing uses (CC0-1.0).
- Subcircuits: none.
- The cells of `tcbn28hpcplusbwp12t30p140` are not included (see `external`).
