# LB_DAC_cunit

Schematic of the Virtuoso cell `RISCA_JL/LB_DAC_cunit` (view schematic), exported with rnl-virtuoso and turned into a TOA circuit with toa-virtuoso.

- `LB_DAC_cunit.scs`: the Spectre netlist, with its drawing in RNL 0.4 records.
- `eda-symbol.rnl`, `eda-style.rnl`: the symbol and style packages the drawing uses (CC0-1.0).
- Subcircuits: none.
- The models of the devices of the process `tsmc28` are not included.
