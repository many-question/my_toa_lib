# tx_sampler_pdk110_11

Netlist of the subcircuit `tx_sampler_pdk110_11` of `pll`, turned into a TOA circuit with toa-virtuoso.

- `11_tx_sampler.scs`: the Spectre netlist, with its drawing in RNL 0.4 records.
- `pll_semantics.rnl`: the part of an RNL package of the source that the drawing uses.
- Subcircuits, each an object of its own (see `uses`): `pll_inv_pdk110_12`, `pll_tg_pdk110_13`.
- The models of the devices of the process `tsmc180` are not included.
