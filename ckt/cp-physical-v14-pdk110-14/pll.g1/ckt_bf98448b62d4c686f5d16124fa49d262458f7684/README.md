# cp_physical_v14_pdk110_14

Netlist of the subcircuit `cp_physical_v14_pdk110_14` of `pll`, turned into a TOA circuit with toa-virtuoso.

- `14_cp_physical_v14.scs`: the Spectre netlist, with its drawing in RNL 0.4 records.
- `pll_semantics.rnl`: the part of an RNL package of the source that the drawing uses.
- Subcircuits, each an object of its own (see `uses`): `pll_inv_pdk110_7`, `pll_nand2_pdk110_15`, `pll_tg_pdk110_16`.
- The models of the devices of the process `tsmc180` are not included.
